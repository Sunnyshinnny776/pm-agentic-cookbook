# Security Reporting

Security issues include unsafe command execution in tool scripts, private-content leaks, exposed credentials,
and workflow defects that could cause unauthorized access or data loss.

Prefer the private vulnerability reporting entry on this repository's GitHub Security page when available.
Otherwise, use an available private contact channel on the maintainer's
[GitHub profile](https://github.com/Sunnyshinnny776). If neither is available, submit only a contact request
without vulnerability details. Do not disclose credentials, customer data or directly exploitable details publicly.

Include the affected version or file, a minimal synthetic reproduction, the impact and a suggested repair.
This repository has no published supported-version list or promised response deadline.
The maintainer determines repair and disclosure arrangements based on impact and reproducibility.
