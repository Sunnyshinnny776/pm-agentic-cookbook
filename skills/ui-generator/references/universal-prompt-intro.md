# ToB 高保真原型生成 · 通用 Prompt

把本文件完整粘贴给任意大模型，即可在不安装任何工具的情况下，从 PRD 生成可交互的 ToB 高保真前端原型代码。

**使用方式**：先给出 PRD（或其中的功能模块描述），以及项目的 UI/UX 规则（没有就说明没有），再粘贴本文件。模型按正文的设计原则、设计令牌与 UI/UX 规则产出 React + TypeScript + Tailwind 页面代码；没有给出项目规则时，按本文件附带的默认 UI/UX 规则生成，并在交付说明里写明。

**两条必须坚持的边界**：

1. 页面、字段、操作与角色权限取自 PRD；PRD 没写的，列为待确认问题，不由模型自行补全。
2. 正文要求运行的脚手架脚本在通用 Prompt 下无法执行；项目尚未初始化时，模型给出初始化步骤由你执行。设计令牌以本文件中附带的 CSS 为准。

以下依次给出：原型生成正文、设计令牌、默认 UI/UX 规则、代码缺陷自查。
