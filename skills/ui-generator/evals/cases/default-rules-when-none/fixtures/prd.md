# 供应商资质审核 · 列表页需求

## 1. 背景

采购部需要集中审核供应商上传的资质文件（营业执照、生产许可证、质检报告），过期或不合格的资质不能参与新的采购。

## 2. 角色

| 角色 | 能做什么 |
| --- | --- |
| 采购专员 | 查看自己负责的供应商资质；删除「待审核」的资质记录 |
| 资质审核员 | 查看全部资质；审核「待审核」的资质，结论为通过或驳回，驳回必须填写原因 |

两个角色使用各自的页面，不共用一个页面。本页只做「资质审核员」的列表页。

## 3. 列表字段

| 列 | 说明 |
| --- | --- |
| 供应商名称 | 文本 |
| 资质类型 | 营业执照 / 生产许可证 / 质检报告 |
| 资质编号 | 文本 |
| 到期日期 | 日期，已过期的在日期后标「已过期」 |
| 提交时间 | 日期时间 |
| 审核状态 | 待审核 / 已通过 / 已驳回 |

## 4. 查询条件

- 搜索：供应商名称、资质编号
- 资质类型
- 审核状态

## 5. 操作

| 操作 | 何时可用 | 规则 |
| --- | --- | --- |
| 详情 | 任何状态 | 打开资质详情，显示文件预览与审核记录 |
| 审核 | 审核状态为「待审核」 | 打开审核面板，选择通过或驳回；驳回原因必填（不超过 200 字）；提交成功后状态变为「已通过」或「已驳回」 |

资质审核员不能删除记录。

## 6. 数据

列表默认按提交时间倒序。
