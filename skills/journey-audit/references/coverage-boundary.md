# coverage-boundary(语义可判 vs 必须视觉)

> 枚举纯语义/文本快照**无法判定、须人工视觉复核**或需额外采集手段的盲区。阶段B 第三步据此标注覆盖边界,并在报告中生成「需人工视觉复核」段。原则:**「未检出异常」≠「无缺陷」**,落入本盲区的维度必须显式上报为"需人眼复核",不得静默放过。

## 盲区分组

### A 纯视觉 / 渲染(信号只存在于像素)

1. 颜色正确性(状态色错误等)。
2. 布局 / 对齐(列错位、栅格塌陷、像素级缩进规则)。
3. 间距 / 留白。
4. 截断 / 溢出(文字被 `…` 截断、意外横向滚动)。
5. 层叠 / 遮挡(弹窗/下拉/tooltip 被盖)。
6. 响应式断裂。
7. 字体 / 字重 / 字体未加载(豆腐块)。
8. DOM 存在但视觉不可见/不可点(opacity:0、移出屏外、被遮挡、宽高 0)。
9. 图标正误(SVG/字体图标,无文字)。
10. 图片 / 图表渲染(canvas 读不到;柱高/占比/趋势)。
11. 加载 / 骨架卡死。
12. 空态插画。
13. 选中 / 激活态仅靠背景色传达(例如宿主规定激活的末级菜单不加粗、只靠背景高亮)。
14. 对比度 / 可读性。

### B 动态 / 时序(单帧静态快照天然丢失)

15. 动画 / 过渡。16. 闪烁 / 错误中间态。17. hover/focus 才出现的内容。18. 瞬时 toast 的时序。19. 滚动相关行为。20. 拖拽/缩放/排序。21. 焦点管理。22. 防抖/节流/竞态。23. 感知性能。24. 光标语义(not-allowed/pointer)。

### C 像素 / 跨帧视觉 diff

25. 视觉回归。26. 数字的视觉强调(标红/告警色)。27. 打印/导出版式。28. 数据可视化正确性。

### D 视觉 vs DOM 不一致

29. 重叠文字可读性。30. RTL/多语言渲染。31. 真实点击命中区域。

## 探针有效性(判定手段本身是否代表真实路径)

盲区讲的是"判不了什么";本节讲"判定手段可能判错什么"。走查为够到某个分支常会使用**绕过 UI 的探测手段**(直接改 DOM 属性、注入 storage、控制台调命令)。这类手段越过了框架层,其观察结果不一定代表真实用户路径:

- **先证明路径可达,再把观察当缺陷**。典型反例:对已置灰按钮强制 `disabled=false` 后点击,观察到"无任何反馈"并据此登记"静默失败"。但 React 不对 `disabled` 元素派发合成事件——它按 props 判断而非读 DOM,该点击到不了任何处理器。这条路径**在框架下不可达**,不构成用户可见缺陷,据此提出的修复(给禁用按钮挂 onClick)是死代码。
- **注入式前置必须显式声明**。为构造前置状态而注入 storage / 直接调服务命令时,该条结论标注"注入前置",与纯 UI 路径区分——它证明的是规则,不是可达性。
- **绕过手段能证明的与不能证明的要写清**。强制点击后"无写入"只能证明"没写进去",不能证明"服务端返回了拒绝"及其文案;后者若靠事后读源码得到,应标为源码证据而非运行期观测。
- 探针本身失灵也要能识别:控件没被命中(如原因字段是 `textarea` 而脚本只采集 `<input>`)会呈现为"操作无效果",与真实缺陷同形。结论存疑时标"不可判定,建议补走",不写成缺陷。

## 可捞回的缓解项(不靠截图也能判)

- **状态色 / 选中态 / 禁用态**:若编码为状态徽标的类名或属性、`aria-selected`、`disabled`,可由语义快照判定 → 归入对应维度,不计入盲区。capture-format 已保留状态语义以回判颜色意图。
- **瞬时反馈(toast/dialog)**:改为**按事件捕获**(capture-format `type=feedback`:toast 经其浮层的 MutationObserver,dialog 经 Node 端 `page.on('dialog')`)→ 纳入 D10 语义判定。
- **真正无解、必须视觉的**:A 组的图标(9)、图表(10)、颜色(1)、布局/对齐(2)、遮挡(5)等核心项。

## 与 audit-dimensions 的交叉对齐

| audit-dimensions | 可判部分(语义) | 落入本盲区的部分 |
| --- | --- | --- |
| D02 状态机一致 | 状态文本 + status 类 | 状态色误用(若仅颜色错、文本/类对) → A1 |
| D06 字段校验 | 报错文案、禁用态 | 校验触发的瞬时高亮/抖动 → B15/16 |
| D09 操作可用性 | 按钮存在/disabled | 光标语义、视觉置灰程度 → B24/A14 |
| D10 反馈语义 | 经事件捕获的 toast/dialog 文本/分级 | toast 出现时长/动画/位置 → B18/15 |
| D12 空/异常态 | 状态文案 | 空态插画/骨架视觉 → A11/12 |
| D14 列表/表格 | 结构、可用性 | 拖拽列宽、排序动效 → B20 |

阶段B 报告须分三类显式列出:**已判定维度** / **需人工视觉复核(定位到旅程步骤 + 对应本文件条目)** / **未覆盖(未审计)项**。
