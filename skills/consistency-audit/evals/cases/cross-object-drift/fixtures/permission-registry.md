# 权限点登记表

> 本表是工作区权限点的唯一出处。

| 编码 | 名称 | 说明 |
| --- | --- | --- |
| `member.view` | 查看成员 | 查看成员列表与角色 |
| `member.invite` | 邀请成员 | 生成邀请链接 |
| `member.manage` | 管理成员 | 修改角色、停用、移出 |
| `link.create` | 创建共享链接 | 为文档生成共享链接 |
| `link.revoke` | 撤销共享链接 | 让自己或他人创建的共享链接失效 |
| `workspace.settings` | 工作区设置 | 修改工作区名称与默认权限 |
