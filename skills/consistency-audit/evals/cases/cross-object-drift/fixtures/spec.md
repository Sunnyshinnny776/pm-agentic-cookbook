# 工作区成员管理 规格

> 版本 1.3

## 1. 角色

工作区成员有四种角色：所有者（owner）、管理者（manager）、编辑者（editor）、访客（guest）。

## 2. 业务规则

| 编号 | 规则 |
| --- | --- |
| R1 | 每个工作区必须始终保留至少一名状态为启用的所有者。任何操作若会使启用的所有者数量变为 0，必须拒绝并提示"工作区至少保留一名所有者"。 |
| R2 | 成员被移出工作区后，该成员创建的全部共享链接立即失效。 |
| R3 | 邀请链接自生成起 7 天后过期；过期链接不能用于加入工作区。 |
| R4 | 权限点目录以《权限点登记表》为唯一出处，代码中的权限目录必须与之逐项一致。 |

## 3. 操作

- 管理者及以上可以邀请成员、修改成员角色、停用成员、移出成员。
- 停用的成员保留在成员列表中，但不能登录该工作区。
