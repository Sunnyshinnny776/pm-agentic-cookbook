# CHANGELOG

## v0.2.1（2026-11-11）

- 明确已有任务授权下按宿主规则处理范围内修复与规定复核，无需重复确认；业务取舍、修改 Oracle 或扩范围仍交用户裁定，审计/测试发现不自行授予实现修改权。
- 补全英文 Model Experience 的上下文预算，保持中文说明与分发内容对应。

## v0.2.0（2026-10-24）

- 破坏性：自动调用以当前目标或已采用工作流所需产出为依据；明确适用用 Allow，实质歧义用 Ask，明确不适用用 Deny。仅比较材料或完成一个任务不自动启动审计。
- 迁移：调用方保留已确认目标、范围与流程步骤；目标明确时照常自动执行，歧义只问一次并等待答复。既定审计的独立性、证据与报告要求保持。

## v0.1.0

- 首个公开版本。
- 核对两个对象是否一致：规则与代码的全部执行路径、需求文档与数据模型、目录与代码镜像、测试规格与业务规则、流程图与模型、引文与源材料。
- 把 Oracle 拆成逐条可核对的条目，逐条判定成立、部分成立、相悖、缺失、强于规定或无法判定；判「缺失」须附检索记录。
- 反查实现有、Oracle 没写的行为；高后果条目用探针、变异或脚本取证，临时改动结束前还原。
- 产出交用户裁定的证据，不宣告一致或通过。
- `scripts/build.py` 生成通用 Prompt 与 `.skill` 安装包；安装包成员使用固定时间戳，重复构建结果一致。
