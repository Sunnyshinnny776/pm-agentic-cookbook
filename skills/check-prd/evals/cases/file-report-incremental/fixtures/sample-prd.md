# HR 业务模块 需求文档

> 本文档为合成语料，非真实项目产出。

## 1. 背景

现有系统每月核算前需人工整理参与核算的人员名单与其档案数据，耗时长且易错。本模块把这一段做成系统能力。

## 2. 范围

| 在范围内 | 不在范围内 |
| --- | --- |
| 核算期间的建立与关闭 | 核算引擎本身 |
| 参与核算人员的同步 | 发放与银行报盘 |
| 人员档案数据的准备与修正 | 申报 |
| 批量导入 | |

## 3. 功能

### 3.1 核算期间

- 管理员建立期间，设定起止日
- 期间有"准备中 / 已锁定 / 已归档"三种状态
- 已锁定的期间不允许再修改人员名单

### 3.2 人员同步

- 从人事系统同步本期间参与核算的人员
- 同步后可手工增减
- 同步失败时提示用户重试

### 3.3 档案数据准备

- 展示每个人的档案数据，支持逐条修改
- 支持批量导入档案数据（Excel）
- 导入后覆盖原数据

### 3.4 异常修正

- 缺少档案数据的人员在列表中高亮
- 用户点击后进入修正页

## 4. 页面

| 页面 | 说明 |
| --- | --- |
| 期间列表 | 展示全部期间与状态 |
| 人员列表 | 展示本期间人员及其档案完备情况 |
| 修正页 | 逐条修改档案数据 |
| 导入页 | 上传文件、查看结果 |

## 5. 角色

- 管理员：全部功能
- 专员：人员列表与修正页

## 6. 验收标准

- 能建立期间并同步人员
- 能导入档案数据
- 能修正缺失数据
- 锁定后不能改名单
