# notes：无可沉淀时是否如实说"无"

## 守护什么

`spec-capture` 的职责是提炼可复用规则。**这类 skill 有一个结构性的失效倾向：被调用了就得产出点什么。**

一旦它开始把"拼写要正确"这类通识写进 spec，后果是双向的——spec 被稀释到没人愿意读，而真正的规则淹没在里面。这比漏掉一条规则更难发现，因为产出看起来是有的。

本 case 检验 skill 正文里"无可沉淀时如实说无"这一条。

## 为什么要有对照组

只测"该说无的时候说不说无"，一个永远回答"无可沉淀"的实现也能满分。**必须同时测它在真有东西时提不提得出来**，两组一起才构成有效判据。

对照组的两个输入是刻意选的：一条来自"同类缺陷第二次出现"，一条来自用户明确裁定。
