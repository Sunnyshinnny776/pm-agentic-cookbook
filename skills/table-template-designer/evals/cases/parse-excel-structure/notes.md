# notes：从表头描述解析出嵌套指标

## 守护什么

把非时间轴的文字结构解析为层级表头，同时保留身份列、可填值、只读边界、计算结果和枚举字段。

## 为什么这样设计

从设备校准前后对同一检测指标进行重复测量这一事实组织列，不沿用 skill 中的组织层级、历史/当期分区或季度月份示例。两个阶段是同一任务的测量阶段，均可采集数据；它们不表示历史区与预算填报区。输入给出可执行的均值和边界判定规则，避免把视觉形状差异当作功能正确性的替代。

## 怎么跑

1. 仓库外空目录安装 table-template-designer 源码，排除 evals、dist 和领域 Provider 实例。
2. 独立冷启动被试，仅发送 input 的“给被试的原话”。
3. 另一位独立冷启动执行者读固定判据、输入、实际产物与完整事件，逐项记录命中、部分命中、不满足或无法判定，并说明可见证据和隔离边界。
