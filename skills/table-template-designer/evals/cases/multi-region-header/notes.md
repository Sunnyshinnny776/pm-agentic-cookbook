# notes：多区域表头与冻结组织列

## 守护什么

复杂表格的核心规范同时生效：冻结列、多级表头的区域划分、级联下拉、汇总列。

## 为什么这样设计

与 `no-over-design` 成对：一个测「该用时用全」，一个测「不该用时不用」。场景用快消门店的营销费用预算，组织层级与费用科目都是通用的零售结构。
