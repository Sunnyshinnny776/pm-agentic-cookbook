# notes：列少时不过度设计

## 守护什么

`table-template-designer` 的适用范围：冻结列、多级表头、级联下拉面向列数多、需要横向滚动的复杂表格；简单表格只遵循基本表格规范，不过度设计。另守护停机条件里的代码缺陷自查。

## 为什么这样设计

边界用例。只测复杂表测不出它会不会把规则套到所有表上；费用报销汇总是通用场景，不带任何行业特征。

## 怎么跑

1. 仓库外建空目录，`.claude/skills/table-template-designer/` 放 skill 源码（排除 `evals/`、`dist/`）。
2. 新会话冷启动，原样发送 `input.md` 的「给被试的原话」。
3. 判卷由独立执行者按 `expected-points.md` 逐条勾选。
