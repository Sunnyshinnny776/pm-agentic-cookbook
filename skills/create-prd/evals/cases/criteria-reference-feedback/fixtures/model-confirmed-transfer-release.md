# 渠道线索Domain Model v1.2

版本：v1.2，模型已确认。

## 1 范围与角色

企业自研的渠道线索管理子功能。渠道专员处理本组线索；组长管理本组分配。线索属于唯一业务组。

## 2 认领与释放

未认领线索可由本组渠道专员认领，进入已认领且认领人为该专员。认领人可释放本人的已认领线索，状态回到未认领。其他人不能释放该线索。

## 3 组内转派

组长可将本组已认领线索转派给另一本组专员，状态仍为已认领，认领人改为接收人。转派人、原认领人和接收人及时间须可追溯；禁止转给其他组专员。

## 4 转派与释放并发最终归属
同一线索在相同起始归属下发生转派与释放并发，最终归属由第一个成功生效的操作决定：先转派生效则归属转派目标，先释放生效则为未认领。这里定义同一归属结果在不同先后条件下的取值，不新增技术返回或其他独立副作用。该业务口径已由用户明确确认。
