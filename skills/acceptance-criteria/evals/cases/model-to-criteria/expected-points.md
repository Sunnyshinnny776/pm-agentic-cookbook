# expected-points：业务标准及确认边界

- [ ] A1 输出有文首范围/依据/状态；正文仅主表、待确认清单和变更记录，按业务类别分节，主表固定五列且不含旅程/测试数据表。
- [ ] A2 每行只核一个业务结果，使用业务语言；不把状态变化和另一项独立通知/记录结果捆成一行。
- [ ] A3 来源具名写门店调拨Domain Model或需求确认书、章节号及节名；不只有业务编号，不引用过程编号，不伪造来源。
- [ ] A4 覆盖提交、接收完成、撤回三条合法流转，覆盖终态不能再次提交/接收；端到端业务场景有可判的起终点条目。
- [ ] A5 数量为空/零或负数/非整数/超可用数量被拒，等于可用数量允许；未编其他限制。
- [ ] A6 覆盖重复提交不新增、商品缺失/可用数量不足和并发不超量；同店约束保留。
- [ ] A7 覆盖三角色的授权与拒绝、来源/接收方向和其他门店数据范围，不扩大审阅员权限。
- [ ] A8 提醒天数未知明确待确认，没有给固定天数；不加无来源的性能/安全数值。
- [ ] A9 AC-01/05内容和确认状态保持，AC-03作废行保留；新增编号从AC-06起续增，不复用02/04或作废编号。
- [ ] A10 新行待确认、文首草稿，待确认清单和变更记录齐全；没有代用户确认或继续写PRD/测试。

- [ ] A11 已确认范围及两个模型可定位，保持一份清单和原编号，不因多模型/下游台账增加正文产物或混入交付验收状态。

合法停下导致无法到达的条目标无法判定，不将无产物当成质量通过；输入齐全而无说明的遗漏仍按实际失守记录。
