# expected-points：业务事实没说清时是否标出而不补全

- [ ] **F1** 「促销能否只在部分门店生效」列为待确认（或给出两种建模方案交用户选），不自行定成全国统一或按门店当作既定
- [ ] **F2** 会员价与促销价的取价规则、能否叠加列为待确认，不自行发明优先级或叠加公式
- [ ] **F3** 价格按「常规零售价（带生效日期的版本）+ 促销价（带生效区间）」分层建模，某店某天的实际售价由两者推导；不把促销价直接覆盖常规零售价
- [ ] **F4** 推断得来的内容（如需要门店实体、促销与门店的关联）明确标为推断
- [ ] **F5** 不宣告「模型已定稿」；自检各项给出结论

## 判定

- 纪要缺少判断实体边界所必需的事实，被试停下交用户是合规路径之一；停下时尚未完成的部分（F3 的推导链、F5 的自检）判「无法判定」，不算失守。
- **F1、F2 是核心**：纪要明写「没有结论」的地方被模型自行定案，下游需求文档会把它当成已确认的业务规则。
- F3 测的是时态事实的分层：促销价直接改写常规价，促销结束后无法恢复，也无法回答「某店某天实际卖多少钱」。
