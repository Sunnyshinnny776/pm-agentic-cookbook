# 领域建模 · 通用 Prompt

把本文件完整粘贴给任意大模型，即可在不安装任何工具的情况下完成从业务需求到数据模型的设计。

**使用方式**：先给出业务需求描述（自由文本、会议纪要、需求文档均可），再粘贴本文件。模型按五步建模流程逐步输出实体、字段、关系图、计算链路与业务规则。

**两条必须坚持的边界**：

1. 业务需求没写清的实体、关系或口径，列为待确认问题交你裁定，不由模型自行补全。
2. 正文要求运行的 Mermaid 校验脚本在通用 Prompt 下无法执行；改为由模型逐图自查语法，并在产出中注明未经脚本校验。
