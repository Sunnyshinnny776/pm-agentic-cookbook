# 可信度分级

> 材料中的每一条结论，在被引用到下游之前都要带一个可信度标签。四级之间的差别不是"可信程度的高低"，而是**可陈述强度的不同**——即这条结论能被写成什么句式。

---

## 四级定义

| 级别 | 何时使用 | 可陈述强度 |
| --- | --- | --- |
| **CONFIRMED** | 来自唯一权威材料，或经用户明确确认 | 可作为规则直接陈述："系统在 X 时执行 Y" |
| **CORROBORATED** | 两份及以上独立材料相互印证，但无单一权威出处 | 可陈述，但需标注依据："据现有材料，X 时执行 Y" |
| **INFERRED** | 由已确认内容推导，或来自参考层材料 | **必须标注为推断**："推断 X 时应执行 Y，待确认" |
| **UNRESOLVED** | 材料之间矛盾，或与实现矛盾，尚未裁定 | **不得陈述为结论**，只能列为待裁定项 |

---

## 使用规则

1. **标签跟着结论走**，不跟着材料走。同一份材料里，用户已裁定过的段落是 CONFIRMED，附录里的举例可能只到 INFERRED。

2. **不得升级，只能降级。** 没有新证据时，INFERRED 不会因为被反复引用而变成 CONFIRMED。升级只有一条路径：用户确认。**用户口头确定，或在报告中标注确定，即视为 CONFIRMED**——不需要更正式的动作。

3. **UNRESOLVED 不是暂存区。** 它是交给用户的裁定清单，每一条都要有明确的两个及以上候选口径，以及各自的出处。写不出候选口径的，说明还没查清，不该进这一级。

4. **下游继承**：基于 INFERRED 结论推导出的新结论，最高也只能是 INFERRED。**推断链不会自我加固。**

---

## 与准入四问的对应

| 四问结果 | 对应级别 |
| --- | --- |
| 权威性通过 | CONFIRMED |
| 权威性降级为参考层 | 该材料所有结论一律 INFERRED |
| 多份非权威材料互相印证 | CORROBORATED |
| 一致性检出冲突 | UNRESOLVED |

---

## 为什么要分级而不是只标"确认/未确认"

两级制会把两种完全不同的情况压成一种：

- "有两份材料都这么说，但没有一份是决策依据" — 可以据此工作，只要说明依据
- "材料之间打架，我挑了一个" — **不可以据此工作**

压成"未确认"之后，前者会被过度回避（该用的不敢用），后者会被悄悄使用（不该用的用了且无人知道）。四级的价值在于把这两类分开。
