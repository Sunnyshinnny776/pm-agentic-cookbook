# 年度采购计划任务需求

## 目标与范围

连锁零售企业按计划年度向门店下发计划任务。门店编制采购计划，区域汇总并提交审批，批准后发布执行。

本次范围为任务列表、门店编制和区域汇总。供应商结算、付款和仓储作业不在本次范围。

## 对象与角色

- 计划周期示例为 CYC-2027。
- 计划任务记录门店、计划周期、状态与计划金额。
- 组织管理员管理本组织任务；组织协管员协助编制。
- 门店示例为东区一店、西区一店，区域为东区、西区。

## 流程

1. 集团总部下发任务，门店填写计划金额。
2. 门店提交后进入区域审核中，区域查看汇总金额。
3. 审批批准后进入待发布，发布后进入执行中。
4. 编制校验失败时提示用户重试。

## 页面

列表显示门店、周期、状态和金额，提供状态筛选。编制页可以保存和提交。区域汇总页展示各门店的计划金额及合计。

## 验收要求

- 能建立周期并下发任务。
- 门店能保存并提交计划金额。
- 区域能查看汇总并发起审批。
- 用户能区分待提交、区域审核中、待发布和执行中。
