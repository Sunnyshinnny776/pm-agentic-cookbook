# 年度采购计划任务 Domain Model

## 范围

本模型描述连锁零售企业的年度采购计划周期和门店计划任务。供应商结算、付款和仓储作业不在范围内。

## 对象与关系

| 对象 | 属性 | 关系 |
| --- | --- | --- |
| 计划周期 | 周期标识、计划年度 | 一个周期包含多个门店计划任务 |
| 计划任务 | 任务标识、所属门店、所属周期、状态、计划金额 | 每个任务属于一个门店和一个周期 |
| 门店 | 门店编码、门店名称、所属区域 | 一个门店属于一个区域，可有多个计划任务 |
| 区域 | 区域标识、区域名称 | 一个区域包含多个门店 |

样本周期为 CYC-2027，区域为东区、西区，门店为东区一店、西区一店。计划金额的精度和币种尚未确认。

## 状态

计划任务使用待提交、区域审核中、待发布、执行中四个状态。门店提交使任务进入区域审核中；审批批准后进入待发布；发布后进入执行中。拒绝、撤回和重复提交的状态语义尚未确认。

## 角色与范围

组织管理员管理本组织任务；组织协管员协助编制。具体操作授权与跨组织数据范围尚未确认，不能从角色名称推断。
