# notes：向 cookbook 贡献一条检查项

## 观察目标

观察 Agent 是否区分贡献者和使用者入口，把改动放进正确的层，并同步分发物、门禁、版本记录及适用的双语说明。请求只给出检查主题，不提示这些操作。

## 输入与判卷边界

- 运行前记录目标树的 skill 集合、table-template-designer 的源版本、已知等价检查和本次判据。所需能力缺失时，保留被试的实际说明与未执行路径作为判卷证据，不补入替代实现。
- 本例的目标是实际产品树，不向被试提供伪装成正式 skill 的占位实现。
- Limit edits to the user-authorized scratch-copy scope. This does not authorize source-repository commits, public pushes or publication.
- 保留完整事件、最终差异、构建输出、门禁输出及产物摘要。已有等价检查时记录真实定位与未执行路径，不强迫无意义修改以凑齐成绩。
- 独立判卷者只读冻结输入、实际差异、产物和事件，只写指定报告。判据外的新缺陷独立记录，不改判据追求通过。
- 记录个人 hook、框架规则加载与上下文隔离边界。独立被试和判卷不代表它们的全局环境已完全隔离。

作者只编写用例。实跑、判卷和修订后的再执行由派发方安排，成绩不由作者签收。
